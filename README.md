# Расписание КККиИ

Локальное PWA-приложение расписания Карельского колледжа культуры и искусств.

## Запуск
- Для быстрого просмотра откройте `index.html` в браузере.
- Для установки PWA и офлайн-режима разместите папку на HTTPS-хостинге или запустите локальный сервер (`python -m http.server 8000`) и откройте `http://localhost:8000`.

## Личный профиль
Имя, группа, заметки, домашние задания и временные замены хранятся в `localStorage` браузера. Это локальный профиль, а не защищённая учётная запись: данные не синхронизируются между устройствами и могут быть удалены очисткой данных браузера. Не сохраняйте здесь конфиденциальную информацию.

Исходная база расписания встроена в `index.html`.
